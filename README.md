# WoW Forever Helper

**A planned, advice-only second-screen companion for *World of Warcraft: Forever* on Windows.**

When you ask it to, the helper would look at your screen and a small addon's snapshot of your character. It would then explain what is going on and suggest what to do next. It is meant to work like reading a guide on another monitor. **It will never click, press keys, or play the game for you.**

**Status: planning only. Nothing is built yet.** See the [plan](docs/PLAN.md) and its [review](docs/PLAN_REVIEW.md).

Contributors: read [AGENTS.md](AGENTS.md) first. This repository is public, and it has strict rules about what must never be committed.
